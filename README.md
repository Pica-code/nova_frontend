# Nova Frontend

> A modern, powerful note-taking and knowledge management platform built with React and TypeScript, designed for organizing thoughts, ideas, and information.

## 📝 About

Nova is an intelligent note-taking platform that helps you capture, organize, and connect your ideas. Perfect for students, researchers, writers, and knowledge workers.

## ✨ Features

- **Rich Text Editor** - Markdown support with live preview
- **Organization** - Folders, tags, and notebooks
- **Search** - Powerful full-text search
- **Linking** - Connect related notes
- **Sync** - Cloud sync across devices
- **Collaboration** - Share and collaborate
- **Templates** - Note templates
- **Dark Mode** - Beautiful dark theme

## 🚀 Getting Started

```bash
git clone https://github.com/Pica-code/nova_frontend.git
cd nova_frontend
npm install
npm run dev
```

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- React Markdown
- Tailwind CSS
